# WHOZ — Product Specification

## Core Loop
Create game → answer 10 questions → share invite → friend guesses → reveal → score → share result → challenge back.

## MVP
Telegram bot, 1v1 games, 4 categories, 10 questions, invite tokens, scoring/reveal, result sharing, profile/statistics, achievements and expiration.

## Not in V1
Payments, ads, groups, chat, AI-generated questions, mobile app, web dashboard.

## Success
کاربر بتواند کل Core Loop را بدون پشتیبانی و بدون خروج از تلگرام کامل کند.
