# WHOZ 🧠

فکر می‌کنی چقدر منو می‌شناسی؟

WHOZ یک بازی اجتماعی تلگرامی است: یک نفر درباره خودش به سؤال‌ها جواب می‌دهد، دوستش حدس می‌زند، سپس جواب واقعی و امتیاز نمایش داده می‌شود.

## V1.0
- ساخت بازی 1v1
- 10 سؤال
- 4 دسته
- لینک دعوت اختصاصی
- Guess → Reveal
- امتیاز و نتیجه
- Share نتیجه
- پروفایل و آمار پایه
- Achievementهای پایه
- انقضای بازی
- SQLite

## اجرا
1. Node.js 20+ نصب کنید.
2. .env.example را به .env تبدیل کنید.
3. BOT_TOKEN را تنظیم کنید.
4. npm install
5. npm run dev

Production: npm run build سپس npm start
