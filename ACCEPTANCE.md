# Acceptance

- /start creates or loads a user.
- New game asks for category.
- Creator answers exactly 10 questions.
- A unique deep-link token is generated.
- Invite opens the intended game.
- Guesser cannot see creator answers before guessing.
- Each question records one guess.
- Final score is 0–100%.
- Result shows correct and incorrect counts.
- Completed games cannot be answered twice.
- Invalid or expired links show a safe error.
- Profile statistics update after completion.
- No Telegram ID is exposed in invite URLs.
